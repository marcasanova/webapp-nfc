# Documentación

Esta carpeta es solo para documentación del repo (guías, checklists, notas).

Los recursos gráficos viven en [`public/`](../public/) y la app / el README los consumen desde ahí:

| Ruta | Contenido |
| --- | --- |
| `public/brand/logo.png` | Logo canónico (`/brand/logo.png`) |
| `public/brand/logo-readme.png` | Logo 320×320 para el README de GitHub |
| `public/screenshots/` | Capturas del README |
| `public/videos/` | Miniaturas de TikTok / Instagram |
| `public/landing/` | Imágenes de la landing |
| `public/social/` | Iconos de redes |

Favicons de Next (`app/icon.png`, `app/apple-icon.png`, `app/favicon.ico`) se generan a partir de `public/brand/logo.png`.
